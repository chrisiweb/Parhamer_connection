Create App for Mac

1) Install Python3, pip3 (already installed?), pyinstaller
2) get py file working
3) goto Path in terminal an enter: 

	pyinstaller -F LaMA.pyw
(probably error, because of tkinter, which is not used), then:
	
	pyinstaller -F LaMA.pyw --exclude-module tkinter

	python3 -m PyInstaller -i icon_lama.icns -F LaMA.pyw


Maybe working someday:
pyinstaller -F -w -i icon_lama.icns LaMA.pyw --exclude-module tkinter

If module not found:

Enter in terminal: pip3.11 install pyqt5 v

Create App bundle:
	
	python3 -m PyInstaller --windowed --icon=icon_lama.icns --name=LaMA --add-data="portable:portable" LaMA.pyw

Create DMG FILE

create-dmg \               
  --volname "LaMA_setup" \                                   
  --volicon "icon_lama_installer.icns" \            
  --window-pos 200 120 \        
  --window-size 450 210 \
  --icon-size 100 \
  --icon "LaMA.app" 10 80 \
  --app-drop-link 210 80 \
  "dist/LaMA_setup.dmg" \
  "dist/LaMA.app"
